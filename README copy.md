# Personal Website Workshop Guide

This folder is ready for GitHub Pages. It contains a static interactive guide, the complete résumé toolkit, four editable Word templates, prompt sheets, and template previews. No build step, package installation, or server is required. The downloads are also embedded into `index.html`, so the guide remains useful as one portable file.

## Publish with GitHub Pages

1. Create or open a GitHub repository.
2. Place `index.html`, `.nojekyll`, and the full `resources` folder in the repository root.
3. Commit and push the files to the `main` branch.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. Open the GitHub Pages URL after deployment finishes.

The same `index.html` can also be opened directly in Chrome, Edge, Firefox, or Safari. The `resources` folder contains separate originals for easier editing and replacement, but the embedded download buttons work without it.

## Updating the guide

Replace `index.html` or files inside `resources`, commit the changes, and push them to the same branch. GitHub Pages will publish the updated version.
