## A prompt is a brief, not a magic phrase

Good prompts reduce ambiguity. They tell the builder what the website is for, where facts come from, what sections are needed, how quality will be judged, and what the visual system should communicate.

The prompt does not need to describe every pixel. It should define the important constraints and leave room for the builder to produce a coherent layout.

## Use five prompt ingredients

1. **Goal:** what the website must help a visitor understand or do.
2. **Facts:** the resume or Master Profile that provides verified content.
3. **Structure:** the sections and actions the experience needs.
4. **Style:** typography, colour, spacing, hierarchy, and field-appropriate presentation.
5. **Guardrails:** what must not be invented, exposed, or overdesigned.

Specific guardrails are more useful than “make it professional.” Say that a missing project must be omitted, an uploaded real portrait may be used, and a fake portrait must never be generated.

## Review the prompt before generating

Remove unused placeholders. Check that requested sections have real content. Confirm that your chosen theme does not contradict the field or make the page hard to read. Then attach the safe resume copy after the prompt so the builder can connect instructions to evidence.
