# Personal Website Workshop Guide

This folder is ready for GitHub Pages. It contains a self-contained static guide with no build step, package installation, or server requirement.

## Publish with GitHub Pages

1. Create or open a GitHub repository.
2. Place `index.html` and `.nojekyll` in the repository root.
3. Commit and push the files to the `main` branch.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. Open the GitHub Pages URL after deployment finishes.

The same `index.html` can also be downloaded and opened directly in Chrome, Edge, Firefox, or Safari.

## Updating the guide

Replace `index.html`, commit the change, and push it to the same branch. GitHub Pages will publish the updated version.
